@codemirror/search

Install this optional package for the search panel, search keymap, selection-match highlighting, and commands such as find next or select all matches.

  • Install: npm install @codemirror/search.
  • Inputs such as [search], [searchConfig], and [searchKeymap] install search behavior.
  • Outputs are not emitted by the search panel.
  • Template reference: #editor gives the button handlers access to the wrapper component instance.
  • This is useful for imperative CodeMirror actions, for example openSearchPanel(), findNext(), or closeSearchPanel().

@codemirror/search

Search panel and selection matches

Configured with [search]="true", [searchConfig]="state.advancedSearchConfig", [searchKeymap]="true", [highlightSelectionMatches]="true", and #editor for method buttons. Try it Click openSearchPanel, search for total, then use findNext and findPrevious. Select a word in the editor to see matching selections highlighted, then use selectSelectionMatches to select all matches.
