Theming

The wrapper receives CodeMirror theme extensions through the [theme] input. The official packaged CodeMirror theme is @codemirror/theme-one-dark. The default white editor theme is built into CodeMirror and does not need a package. The dropdown also includes community themes from @ddietr/codemirror-themes and thememirror.

  • Inputs use [theme] to pass one theme extension or an array of extensions.
  • Official package: install One Dark with npm install @codemirror/theme-one-dark.
  • Default light: pass an empty theme array, or omit [theme].
  • Community packages: install the demo community themes with npm install @ddietr/codemirror-themes thememirror.
