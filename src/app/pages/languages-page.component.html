Language support

CodeMirror languages are installed separately and passed to the wrapper through the [language] input. The first examples show the same content in read-only and editable mode.

  • Inputs are Angular property bindings, such as [content], [language], and [readOnly].
  • [content] is the editor document text. It accepts a string; use '' for an empty editor. In the example code is a string variable.
  • [readOnly] controls whether CodeMirror should allow document changes. It accepts true or false.
  • [readOnly]="true" shows code without editing. [readOnly]="false" lets the user type and emit (contentChange).
