Panels and tooltips

Panels render fixed editor UI above or below the editor. Tooltips render positioned UI for a document location, and hover tooltips can appear only when the pointer is over matching text.

  • Inputs such as [panels], [tooltips], and [hoverTooltip] pass CodeMirror UI providers.
  • Outputs are usually not needed; use methods such as activateHover() and closeHoverTooltips() for imperative UI actions.
