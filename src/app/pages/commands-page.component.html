@codemirror/commands

Install this optional package for editing commands such as undo, redo, indentation, line movement, comment toggles, and multiple cursor helpers.

  • Install: npm install @codemirror/commands.
  • Inputs such as [indentWithTab] and [keymaps] register command behavior.
  • Outputs are indirect: commands that edit the document can trigger (contentChange) and (update).
  • Template reference: #editor exposes the Angular wrapper instance inside the template to call methods like for instance addCursorAbove(), addCursorBelow(), selectLine(), indentMore(), toggleLineComment().

Command methods and keymaps

Configured with [indentWithTab]="true", [keymaps]="state.assistKeymaps", [appendExtensions]="state.commandHistoryExtensions", [multipleSelections]="true", [drawSelection]="true", and #editor for command buttons. Try it Click addCursorAbove or addCursorBelow to create extra cursors. Use comment and indent to run command methods from Angular code, then use undo and redo to verify command history. Press Tab in the editor to test the [indentWithTab] key binding.
