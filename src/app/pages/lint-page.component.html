@codemirror/lint

Install this optional package to show diagnostics produced by your own linter function. Diagnostics can appear inline and in a lint gutter.

  • Install: npm install @codemirror/lint.
  • Inputs such as [lint], [linter], [lintConfig], [lintGutter], and [lintKeymap] enable diagnostics.
  • Outputs are not emitted for diagnostics; your linter function is called by CodeMirror when linting runs.

@codemirror/lint

Diagnostics and lint gutter

Configured with [lint]="true", [linter]="state.assistLinter", [lintConfig]="state.advancedLintConfig", [lintGutter]="true", [lintKeymap]="true", and [lineWrapping]="true". Try it The demo linter marks var as a warning and console.log as an info diagnostic. Look for diagnostic markers in the editor and in the lint gutter beside the line numbers.

Diagnostic source

  • state.assistLinter scans the current document text.
  • It returns CodeMirror diagnostics with from, to, severity, and message.
  • The wrapper passes that function to CodeMirror through [linter].
