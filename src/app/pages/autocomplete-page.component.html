@codemirror/autocomplete

Install this optional package when you need completion popups, custom completion sources, or automatic bracket closing. The wrapper loads it only when these APIs are used.

  • Install: npm install @codemirror/autocomplete.
  • Inputs such as [autocompletion], [completions], and [closeBrackets] require this optional package.
  • Language autocomplete uses completion data provided by the active CodeMirror language, for example TypeScript keywords and syntax-aware suggestions.
  • Custom completion source adds app-specific suggestions, such as domain objects, API names, snippets, or values returned by your backend, alongside language completions.
  • Outputs are not emitted by completion itself; inspect state with methods such as closeCompletion(), acceptCompletion(), startCompletion().

@codemirror/autocomplete

Language autocomplete

Configured with [autocompletion]="true", [autocompletionConfig], [closeBrackets]="true", and #editor for method buttons. Try it Click startCompletion or type near TypeScript code to open the completion popup. Type an opening bracket, quote, or parenthesis to see [closeBrackets] insert the matching character.

Custom completion source

Configured with [autocompletion]="true" and [completions]="assistCompletions". The completion source returns the demo options currentUser, saveUser, and console.log. Try it Start typing save, current, or console. Those suggestions come from the Angular field passed to [completions] and are added beside language completions.
